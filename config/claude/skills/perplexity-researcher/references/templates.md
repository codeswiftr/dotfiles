# Research Prompt Templates

Copy and customize these templates for common research scenarios.

---

## Technology & Development

### Technical Deep Dive
```
Provide a comprehensive technical analysis of [TOPIC]:

1. **Overview**: What is it and why does it matter?
2. **Architecture**: How does it work internally?
3. **Implementation**: How to use it in practice?
4. **Performance**: Benchmarks and optimization tips
5. **Ecosystem**: Related tools and integrations
6. **Future**: Roadmap and community direction

Include code examples where relevant.
Cite official documentation and recent articles (2024-2025).
```

### Framework/Library Comparison
```
Compare [FRAMEWORK A] vs [FRAMEWORK B] for [USE CASE]:

Create a detailed comparison covering:
| Aspect | [A] | [B] |
|--------|-----|-----|
| Performance | | |
| Learning Curve | | |
| Community Size | | |
| Documentation | | |
| Enterprise Support | | |
| Bundle Size | | |

Include:
- Pros and cons of each
- When to use which
- Migration considerations
- Real-world adoption examples

Provide a clear recommendation with reasoning.
```

### API Investigation
```
Investigate the [API NAME] API:

1. **Authentication**: Methods and best practices
2. **Endpoints**: Key endpoints with examples
3. **Rate Limits**: Limits and handling strategies
4. **Pricing**: Cost structure and tiers
5. **SDKs**: Available client libraries
6. **Gotchas**: Common issues and solutions

Include official documentation links.
Note any recent changes or deprecations.
```

### Security Best Practices
```
Research current security best practices for [DOMAIN/TECHNOLOGY]:

- OWASP recommendations (2024-2025)
- Common vulnerabilities and mitigations
- Authentication/authorization patterns
- Data protection requirements
- Compliance considerations (GDPR, SOC2, etc.)
- Security tooling and automation

Prioritize authoritative sources.
```

## Business & Market

### Competitive Analysis
```
Analyze the competitive landscape for [MARKET/PRODUCT CATEGORY]:

1. **Market Overview**: Size, growth, key trends
2. **Top Players**:
   - Company profiles
   - Market share estimates
   - Key differentiators
3. **Feature Matrix**: Compare key capabilities
4. **Pricing Analysis**: Pricing models and tiers
5. **SWOT Analysis**: For top 3 competitors
6. **Market Gaps**: Underserved needs

Include recent funding, partnerships, and news.
```

### Market Research
```
Research the [INDUSTRY/MARKET] market:

- Current market size and growth projections
- Key drivers and trends
- Major players and market share
- Customer segments and needs
- Regulatory environment
- Technology trends impacting the market
- Emerging opportunities and threats

Focus on data from 2024-2025.
Include sources with publication dates.
```

### Pricing Strategy Research
```
Research pricing strategies for [PRODUCT TYPE]:

- Common pricing models in the industry
- Pricing tiers and feature segmentation
- Freemium vs paid-only analysis
- Competitor pricing benchmarks
- Value-based pricing approaches
- Discount and promotion patterns

Include specific examples with price points.
```

- Risk factors

## Template Customization Tips

1. **Be specific**: Replace [PLACEHOLDERS] with exact terms
2. **Set timeframes**: Specify recency requirements (2024-2025)
3. **Request structure**: Ask for specific output formats
4. **Require sources**: Always request citations
5. **Scope appropriately**: Break large topics into focused queries
6. **Iterate**: Use follow-up queries to drill deeper
